# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅ Yes    |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities by email: **tonyblard55@gmail.com**

Include as much detail as possible: affected version, steps to reproduce, and potential impact.
You will receive a response as soon as possible.

Please **do not disclose the vulnerability publicly** until it has been resolved.
