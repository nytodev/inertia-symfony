# Security Policy

## Supported Versions

Only the latest version is supported. Always use the latest release.

| Version | Supported |
|---------|-----------|
| 2.x     | ✅ Yes    |

## Reporting a Vulnerability

If you believe you have found a security vulnerability directly affecting this bundle, please **do NOT report it publicly**.

Send a detailed report by email to **tonyblard55@gmail.com** or via [GitHub private vulnerability reporting](https://github.com/nytodev/inertia-bundle/security/advisories/new).

Include: affected version, steps to reproduce, and potential impact. You will receive a response as soon as possible. Please do not disclose the vulnerability publicly until it has been resolved.

Only vulnerabilities directly affecting `nytodev/inertia-bundle` should be reported here. Flaws affecting dependencies (Symfony, Twig, PHP...) should be reported to the relevant projects.
